# 高精度直线运动模组

> 毕业设计：用于微型实验平台的高精度直线运动模组设计与实现  
> 郑州轻工业大学 电子信息学院 Z电信工程24-01 | 郑天赐 | 2026

## 简介

基于 STM32F103C8T6 的闭环直线运动控制系统。57步进电机 + SIKO MSK200/1 磁栅尺全闭环反馈，**重复定位精度 ±2μm**。

## 硬件

| 组件 | 型号 |
|------|------|
| 主控 | STM32F103C8T6 |
| 电机 | 57两相步进电机 |
| 驱动器 | DM542（16细分，3200脉冲/转） |
| 丝杆 | 1204滚珠丝杆（导程4mm） |
| 传感器 | SIKO MSK200/1 磁栅尺（1μm分辨率） |
| 隔离 | YH-CD44 光耦模块（5KV隔离） |

## 功能

- **速度模式**：开环匀速，方向可切换
- **位置模式**：位置式PID闭环定位，指数衰减软着陆，零超调
- **六阶段自动回零**：FAST→BACK→SLOW→OFFSET→Z_FINE→DONE，Z相精定位±1μm
- **限位保护**：硬件限位 + 软件限位双重保护
- **自动循环测试**：长时间可靠性验证（350+分钟，350+次到达，0超差）

## 软件架构

```
Core/Src/main.c              主程序：模式调度、按键、限位、状态打印
├── motor.c/h                 电机驱动：TIM1动态STEP频率、方向控制
├── encoder.c/h               编码器：32位累加器，无绕回位置跟踪
├── pid.c/h                   位置式PID：Kp=5.0, Ki=0.03, Kd=1.5
├── homing.c/h                六阶段回零状态机
└── stm32f1xx_it.c            中断：TIM2 Z相捕获 + TIM4 1kHz PID
```
